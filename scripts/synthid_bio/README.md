# SynthID Bio detector architecture

`detector.py` implements the geometric features and five-layer network
architecture described in [supplementary Listing 1][supplement] of
[Stutz et al.][paper].

We do not publish an operational scorer, detector parameters, checkpoint
extraction code, or thresholding interface. The retained code documents only
the architecture used in our research experiment.

[paper]: https://doi.org/10.1038/s41586-026-10965-y
[supplement]: https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-026-10965-y/MediaObjects/41586_2026_10965_MOESM1_ESM.pdf
